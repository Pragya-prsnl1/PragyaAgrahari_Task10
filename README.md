# WashMate – Laundry Service Website

This is a responsive laundry service website named **WashMate**, created as part of my MERN Stack course assignment at Tutedude.

The project focuses on practicing HTML and CSS, including Flexbox, responsive design, navigation bars, and CSS animations.

## Features

- Responsive navigation bar with Home, Services, About Us, and Contact Us links.
- Mobile-friendly navigation menu.
- CSS-based mobile menu toggle using the `:focus` pseudo-class.
- Animated image with floating, rotating, scaling, and bouncing effects.
- Clean and simple user interface.
- Responsive layout for different screen sizes.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Media Queries
- CSS Keyframe Animations

## What I Learned

While building this project, I practiced:

- Creating and styling navigation bars.
- Using Flexbox for layout alignment.
- Making websites responsive using media queries.
- Using pseudo-classes like `:focus`.
- Creating animations using `@keyframes` and `transform`.
- Combining translation, rotation, and scaling to create a floating and bouncing image animation.

## Project Purpose

The purpose of this assignment was to improve my HTML and CSS skills and gain more hands-on experience in building responsive website layouts.
